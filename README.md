# Al-Maghrebi - Restaurant Marocain

Un site web professionnel pour un restaurant marocain traditionnel, développé avec React, Redux, Vite et TailwindCSS.

## 📋 Fonctionnalités

- **Design Responsive** : Interface adaptative pour tous les appareils
- **Animations et transitions** : Expérience utilisateur fluide avec Framer Motion
- **Panier d'achat** : Système complet pour commander des plats en ligne
- **Gestion des réservations** : Formulaire interactif pour réserver une table
- **Page de menu interactive** : Navigation par catégories de plats
- **Page À propos** : Présentation du restaurant et de son histoire
- **Page Contact** : Formulaire de contact et informations de localisation

## 🚀 Technologies utilisées

- **React** : Bibliothèque front-end pour la construction d'interfaces utilisateur
- **Redux** : Gestion d'état global pour l'application
- **Vite** : Outil de build rapide pour le développement
- **TailwindCSS** : Framework CSS utilitaire pour le design responsive
- **Framer Motion** : Bibliothèque d'animations pour React
- **React Router** : Navigation entre les pages

## 🛠️ Installation et démarrage

### Prérequis
- Node.js (v14+)
- Bun (recommandé) ou npm/yarn

### Installation

```bash
# Cloner le dépôt
git clone https://github.com/votre-nom/restaurant-marocain.git
cd restaurant-marocain

# Installer les dépendances
bun install

# Démarrer le serveur de développement
bun run dev
```

### Construction pour la production

```bash
# Créer un build de production
bun run build

# Prévisualiser le build de production
bun run preview
```
